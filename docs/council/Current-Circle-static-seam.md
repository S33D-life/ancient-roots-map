# Current Circle → existing static Council

Baseline: `9e478d18fb0143834e96a855d2b21a3026a65281`.

The static `public/tetol/circle-235/pre-fire` package unpacks embedded assets/template through loader.js, then executes classic-1 (Tree data), classic-2 (rich Council registry and presentation layers), and entry.js (UI/Three renderer). classic-3 retains the companion presentation experiment. The existing `#croom` hash selects the Deck during startup; no new arrival mechanism is needed.

`npm run council:static` bundles the pure approved Current Circle projection into a local current-circle.js artifact. No edge endpoint, Supabase SDK, database request or external data fetch is introduced. The artifact loads before classic-2. Its adapter fills the legacy presentation manifest before existing consumers bind room labels. Release-check and CI verify artifact freshness.

Weekly fields no longer authored in the current embedded manifest: title, central_question.text/final, fire display/open-state lines, and Council destination. The standing Meet href is cleared and can only come from an approved Current Circle fire link. Circle number remains the static package appearance identifier: the adapter requires it to match the approved number, refusing to relabel old companion geometry as a future Circle. Missing/draft/mismatched adapter state blocks entry rather than rendering stale weekly labels.

Preserved: geometry, vendor modules, embedded assets, companion names/roles/cards, learning threads, relationships, historical Circles and atmosphere. The decoded template is identical to baseline except for the adapter script insertion. Embedded asset manifest is unchanged. Companion presentation is deliberately not generalised or reordered.

Return: Explore opens a separate tab, retaining the original 2D Council state and scroll position; Deck already does so. A single fixed Return to Council of Life affordance stays above the spatial stage, using the approved Council route and fixed #next-gathering section on the current site origin. A fixed from=spatial-council marker lets the Council page restore that section after its entrance, even when auth startup clears the hash. The return stays directly accessible at phone width without depending on the menu. Direct-entry visitors also have that return path. No caller redirect parameter or dependency on window.opener.

Limitations: static companion appearance names, learning memories and historical chronology remain duplicated by design; this is a labels/destinations seam, not full rich-manifest removal. Future Circle packages require their own approved appearance and adapter match. Calendar/fire scheduling is not in Current Circle and cannot be inferred. Other prototype links/actions and local experimental offerings remain unchanged. The return retains the original tab, rather than sharing transient React state between tabs. Trace evidence showed #79 interception blocks the header/menu return. Only the return affordance is placed above the stage; stage pointer handling and all broader #79 work remain untouched.

No deployment, backend publication, Telegram behaviour/send/test, operational change, PDF/share recovery or production action. Draft TEOTAG review only.
